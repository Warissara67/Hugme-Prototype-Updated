# รูปภาพของเว็บ

วางไฟล์รูปในโฟลเดอร์นี้ตามชื่อที่ระบุด้านล่าง เว็บจะดึงไปแสดงเองอัตโนมัติ
**ช่องไหนที่ยังไม่มีไฟล์ ระบบจะวาดภาพประกอบแทนให้** หน้าเว็บจึงไม่มีช่องว่างหรือไอคอนรูปเสีย

ถ้าต้องการเปลี่ยนชื่อไฟล์หรือเพิ่มเครดิตช่างภาพ แก้ได้ที่ `src/data/images.ts`

---

## ข้อกำหนดของไฟล์

| หัวข้อ | ค่าที่แนะนำ |
| --- | --- |
| นามสกุล | `.jpg` (หรือ `.webp` ถ้าต้องการไฟล์เล็กกว่า — อย่าลืมแก้ชื่อใน `images.ts` ด้วย) |
| ขนาดภาพเปิดหน้า | กว้าง 2000–2400 px แนวนอน |
| ขนาดภาพทั่วไป | กว้าง 1200–1600 px |
| ขนาดไฟล์ | ไม่ควรเกิน 400 KB ต่อรูป |
| แนวภาพ | ถ่ายแนวนอนเป็นหลัก ยกเว้นที่ระบุว่าแนวตั้ง |

> **บีบอัดรูปก่อนใส่** ลากไฟล์ไปที่ https://squoosh.app แล้วเลือก MozJPEG คุณภาพ 75
> รูปจากมือถือมักมีขนาด 3–5 MB ซึ่งทำให้เว็บโหลดช้ามากบนสัญญาณในพื้นที่

## เริ่มจากไหนดี

ถ้ามีเวลาถ่ายจำกัด เรียงตามลำดับนี้ ผลกับหน้าเว็บมากที่สุดก่อน

1. `hero-chamchuri.jpg` — ภาพเดียวที่คนเห็นก่อนตัดสินใจว่าจะอ่านต่อไหม
2. `stop-chamchuri.jpg` — จุดไฮไลต์ของเส้นทาง
3. `shop-exterior.jpg` และ `shop-terrace.jpg` — บอกว่าร้านหน้าตาเป็นอย่างไร
4. รูปชา 3 ตัวที่ร้านมีจริง (กุหลาบ เลม่อน เก๊กฮวย)
5. รูปฤดูทั้ง 3 — ช่วยตั้งความคาดหวังให้ถูกก่อนลูกค้าเดินทางมา
6. ที่เหลือทยอยเติมภายหลังได้

## ตรวจว่าช่องไหนยังไม่มีรูป

รันเว็บด้วย `npm run dev` แล้วเลื่อนดู ช่องที่ยังไม่มีรูปจะขึ้นแถบสีเข้มบอกว่า
**ยังไม่มีรูป · (คำอธิบายว่าควรเป็นรูปอะไร)** แถบนี้จะไม่แสดงตอน build ขึ้นจริง
