# HUG ME — Interactive Prototype

ต้นแบบเว็บไซต์โฮงชาฮักมีสำหรับนำเสนอหัวข้อโครงงาน ปรับปรุงจากไฟล์ต้นฉบับของผู้ใช้

## เปิดใช้งาน

ใช้ Node.js 22.12 ขึ้นไป (หรือ Node.js 24 LTS) จากนั้นเปิด Terminal ในโฟลเดอร์นี้:

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

เปิด http://127.0.0.1:5173

```sh
npm run build
npm run preview
node scripts/test-domain.mjs
npx tsc --noEmit
```

## สิ่งที่ทดลองได้

- หน้าแรกแนวธรรมชาติ โทนเขียว ครีม ทอง พร้อมภาพจากต้นแบบเดิม
- เปลี่ยนภาษาส่วนติดต่อผู้ใช้ทั้งเว็บ ไทย อังกฤษ จีน
- แผนผังสถานที่กดเลือกดูรายละเอียดได้ ไม่ใช้ Google Maps API
- รายการชา 18 ชนิด ค้นหา กรองหมวดหมู่ เรียงราคา อ่านรายละเอียด และเพิ่มลงตะกร้า
- แบบทดสอบ 3 ข้อ แนะนำชาด้วย Weighted Scoring และแสดงคะแนน
- QR Code จริงสำหรับหน้ารวมชา หรือหน้าชาแต่ละชนิด พร้อมดาวน์โหลด PNG
- สมาชิกจำลอง ข้อมูลที่อยู่ ประวัติคำสั่งซื้อ รีวิว และเลือกรับข่าวสาร
- แนบภาพตัวอย่างเป็นสลิป แล้วทดลองยืนยันคำสั่งซื้อ
- หลังบ้าน: ตรวจภาพสลิป ยืนยันชำระเงิน จัดเตรียมสินค้า บันทึกบริษัทขนส่ง/เลขพัสดุ และจัดส่ง
- กันจำนวนสินค้าระหว่างรอคำสั่งซื้อ ตัดสต๊อกจริงในข้อมูลจำลองครั้งเดียวเมื่อจัดส่ง และคืนจำนวนที่กันเมื่อยกเลิกก่อนจัดส่ง
- แก้ราคา จำนวนสินค้า การแสดงสินค้า และชื่อ/คำอธิบายชาตามภาษาที่เลือก
- แก้ข้อความประชาสัมพันธ์และช่วงวันที่ เพิ่ม/ลบลิงก์คลิปรีวิว แก้คำอธิบายสถานที่ และซ่อน/แสดงรีวิว
- ภาพรวมยอดขายที่ยืนยันแล้ว จำนวนคำสั่งซื้อ คะแนนรีวิว และกล่องอีเมลจำลอง

## ลำดับสาธิตแนะนำ

1. หน้าแรก → เที่ยวฮักมี → กดจุดบนแผนผัง
2. ค้นหาชาที่ใช่ → ตอบคำถาม → เปิดรายละเอียด → เพิ่มลงตะกร้า
3. บัญชีสมาชิก → ใช้ข้อมูลตัวอย่างที่เตรียมไว้ → เริ่มทดลองเป็นสมาชิก
4. ตะกร้า → แนบภาพตัวอย่าง (ใช้รูปชาใน public/photos/products ได้) → ยืนยันคำสั่งซื้อสาธิต
5. ด้านล่างเว็บไซต์ → ทดลองหลังบ้าน → เปิดหลังบ้านสาธิต
6. ยืนยันการชำระเงิน → เริ่มจัดเตรียม → กรอกขนส่ง/เลขพัสดุ → จัดส่งแล้ว
7. กลับบัญชีสมาชิกเพื่อตรวจสถานะและอีเมลจำลอง
8. หลังบ้าน → QR Code → เลือกชา → ดาวน์โหลด QR

## ขอบเขตของต้นแบบ

ข้อมูลถูกเก็บใน localStorage ของเบราว์เซอร์เครื่องเดียว ไม่มีฐานข้อมูลหรือการยืนยันตัวตนจริง ไม่รับชำระเงินจริง และไม่ส่งอีเมลจริง การออกจากโหมดสมาชิกเป็นเพียงการออกจากบัญชีสาธิต ไม่ใช่มาตรการปกป้องข้อมูล

ใช้ข้อมูลสมมติเท่านั้น ภาพสลิปอยู่ในหน่วยความจำของหน้าเว็บและหายหลังรีเฟรช โดยยังเก็บชื่อไฟล์ไว้เพื่อแสดงประวัติ ต้องสร้างคำสั่งซื้อใหม่หากต้องการทดสอบตรวจภาพอีกครั้ง

ราคา สต๊อก ค่าจัดส่ง ระยะทาง เกณฑ์คะแนน ชื่อแปล และคำอธิบายชาเป็นข้อมูลตั้งต้นสำหรับการนำเสนอ ต้องตรวจสอบกับร้านก่อนใช้งานจริง แผนผังไม่ใช่มาตราส่วน/เส้นทางนำทาง ระบบยังไม่มีการจองกิจกรรม การติดตามขนส่งอัตโนมัติ Payment Gateway หรือรายงานเชิงวิเคราะห์ขั้นสูง

QR ที่ชี้ localhost เปิดได้เฉพาะเครื่องที่รันเว็บ หากจะสแกนจากมือถือ ให้ใช้ URL ที่เผยแพร่จริงแล้วสร้าง QR ใหม่

ลิงก์รีวิวและข้อมูลโปรโมชั่นเริ่มต้นเว้นไว้ตามข้อมูลที่มี เพื่อไม่สร้างรีวิวหรือส่วนลดที่ร้านไม่ได้ยืนยัน เนื้อหาที่ผู้ใช้กรอก เช่น รีวิวและลิงก์คลิป ไม่ถูกแปลอัตโนมัติ

## โครงสร้างและเทคโนโลยี

คง React / TanStack Start / Vite / Tailwind ของต้นฉบับ ไม่ได้ย้ายเป็น Next.js ตามเอกสารเสนอหัวข้อ หากใช้ต้นแบบนี้เป็นฐานระบบจริงควรปรับสถาปัตยกรรมและเอกสารให้ตรงกัน

- `src/hugme/app.tsx` หน้าตาและการโต้ตอบของต้นแบบ
- `src/hugme/model.ts` ข้อมูลตัวอย่าง กฎสต๊อก สถานะคำสั่งซื้อ และการให้คะแนนชา
- `src/hugme/hugme.css`, `details.css` รูปแบบและหน้าจอมือถือ
- `src/routes/` จุดเข้าหน้าเว็บของ TanStack Router
- `public/photos/` ภาพจากต้นแบบต้นฉบับ
- `scripts/test-domain.mjs` ตรวจตรรกะคำสั่งซื้อและการแนะนำชา

ไฟล์ ZIP สำหรับส่งต่อไม่รวม node_modules, Git history, ไฟล์ตั้งค่าส่วนตัว หรือผลการ build จึงต้องติดตั้ง dependencies ก่อนเปิดใช้งาน
